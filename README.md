# kabadiwala-connect
AI-powered platform connecting citizens, informal waste collectors, and formal recyclers to streamline waste collection, improve transparency, and strengthen the recycling chain.

Kabadiwala Connect is a digital platform designed to connect households,
waste collectors, and recyclers while improving transparency,
traceability and efficiency in the recycling chain.

## Project Structure

- `android-app/` — Android application
- `ai-service/` — AI/ML services
- `backend/` — Backend APIs and business logic
- `recycler-portal/` — Recycler interface
- `admin-panel/` — Administration and analytics
- `docs/` — Technical documentation
- `scripts/` — Development and deployment scripts
- `tests/` — Automated and integration tests

## Technology

### Android
- Kotlin
- Jetpack Compose
- Firebase
- Room

### Backend
- API-based architecture
- Firebase integration where applicable

### AI/ML
- Python
- Image classification
- Weight estimation
- Price estimation
- Anomaly detection
- Matching

## Development

This repository contains multiple components that work together as
one platform.

The Android application is the primary mobile interface.

AI and backend services are integrated through defined service/API
boundaries.
